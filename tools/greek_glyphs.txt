# Greek glyphs for the Atari backend's system-font sizes, drawn for
# retroplat in the style of the ST's own 8x16 and 8x8 system fonts:
# two-pixel strokes, the letter in columns 0-6, column 7 the gap.
# Original drawings, not taken from any font.
#
#   8x16: the baseline is row 13, lowercase from row 5, capitals and
#         ascenders from row 2, descenders rows 14-15.
#   8x8:  the baseline is row 6, lowercase from row 2, capitals and
#         ascenders from row 0, descender row 7. Its block has a row -1
#         first, for the dialytika over a capital, which has no room in
#         the cell.
#
# Each glyph is "== name", then "16:" and 16 rows, then "8:" and 9 rows
# (-1 to 7). A row's length is the glyph's advance; '#' is ink. An
# overlay (a name starting "over_") draws over the character before it
# and has no advance of its own.
#
# tools/make_greek_glyphs.py turns this into backends/atari/greek_glyphs.h.
